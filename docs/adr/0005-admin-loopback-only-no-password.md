# ADR 0005: 管理界面仅回环访问、免密码——安全边界靠网络层而非凭证

- 状态：已接受（Accepted）
- 日期：2026-08-20

## 背景（Context）

Web 配置界面能读写所有 provider 密钥与下游密钥，是最高权限面。用户要求"只能本机访问，无需密码"。但网关的 `host` 可配成 `0.0.0.0`（远程 agent 接入场景），此时不加防护，管理界面会暴露给整个局域网。

## 决策（Decision）

- **按来源 IP 检查**：`/admin/*` 请求在中间件里检查远端地址，非回环（127.0.0.1 / ::1）一律 403，**与 host 配置无关**。
- **不引入管理密码**：回环即信任；`admin_password` 字段不加入配置。
- 管理界面与 `/v1/*`（agent 用，走 keys 鉴权）是两个互不影响的访问面。

## 后果（Consequences）

正面：

- 无论 host 怎么配，管理界面只对本机可见，无需维护第二套凭证
- 免密码 = 零凭证管理负担，符合本机自用定位

负面/约束：

- **无法从远程管理**：需要远程改配置时必须 SSH 到本机（或通过隧道把 127.0.0.1 端口转发出来，此时转发层负责鉴权）
- 若将来要远程管理，需重新引入凭证方案（届时加 `admin_password` 或接入既有 SSO）

备选被否决的原因：独立管理端口只监听 127.0.0.1 与"按来源 IP 检查"效果等价但多一个端口要维护；复用现有 keys 当管理口令会让 agent 凭证和管理员身份耦合，且泄露一个 agent key 就等于拿到管理权限；完全不防护不可接受。
